# JoyCafe menu pictures

Place each product picture in its matching category folder. Every folder contains
a checklist of its menu products and their recommended filenames:

- `coffee/`
- `exotic/`
- `latte/`
- `main-course/`
- `non-coffee/`
- `snacks/`

Use lowercase kebab-case filenames matching the menu name. For example:

- `coffee/americano.webp`
- `latte/butterscotch.webp`
- `main-course/nasi-goreng.webp`
- `snacks/french-fries.webp`

WebP is preferred for smaller website downloads. JPG and PNG also work.
